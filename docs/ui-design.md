请为一个「AI 数学方程绘图智能体」设计 Web 端产品界面。该产品支持用户通过自然语言或数学公式输入需求，例如“画 y = x”、“帮我画一条经过原点、斜率为 2 的直线”、“比较 y=x 和 y=x²”，系统会自动理解并在右侧绘制函数曲线，同时在对话中解释图像特征。

整体界面采用三栏式工作台布局：

```text
左侧：会话管理区，可收起
中间：AI 自然语言对话区
右侧：绘图结果查看区
```

---

### 1. 整体风格要求

界面风格希望简洁、现代、专业，适合学生、老师、科研人员和数学学习者使用。整体可以参考 AI 工作台、数据分析 Copilot、数学绘图工具、轻量级 IDE 的视觉体验。

设计关键词：

```text
简洁
专业
智能
高效
数学感
科技感
易用
```

建议使用浅色主题为主，可预留深色主题扩展。页面需要有清晰的信息层级、良好的留白、舒适的阅读体验。

---

### 2. 页面整体布局

请设计一个桌面端 Web 界面，采用三栏布局：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部栏：Logo / 当前项目名 / 分享 / 导出 / 设置 / 用户头像       │
├───────────────┬────────────────────────┬─────────────────────┤
│ 左侧会话管理   │ 中间 AI 对话区           │ 右侧绘图结果区        │
└───────────────┴────────────────────────┴─────────────────────┘
```

推荐比例：

```text
左侧会话栏：240px，可收起为 56px
中间对话区：约 40%
右侧结果区：约 45%
顶部栏高度：56px - 64px
```

需要考虑浏览器全屏工作台体验。

---

### 3. 顶部栏设计

顶部栏包含：

1. 产品 Logo 和名称  
   示例名称：AI 数学绘图智能体 / MathGraph AI

2. 当前项目或会话标题  
   例如：  
   ```text
   二次函数图像分析
   ```

3. 常用操作按钮：

   ```text
   保存
   分享
   导出
   设置
   ```

4. 用户头像或账户入口

顶部栏整体不要太重，保持简洁，突出当前工作内容。

---

### 4. 左侧：会话管理区

左侧是会话/项目管理区，支持收起和展开。

展开状态下包含：

1. 新建按钮：

   ```text
   + 新建绘图
   ```

2. 搜索框：

   ```text
   搜索会话、方程、关键词
   ```

3. 会话分组：

   ```text
   今天
   昨天
   最近 7 天
   收藏
   更早
   ```

4. 会话列表项示例：

   ```text
   y=x² 抛物线分析
   sin(x) 与 cos(x) 对比
   一次函数练习
   圆与直线交点
   ```

5. 每个会话项需要支持：

   ```text
   选中状态
   重命名
   删除
   收藏/置顶
   更新时间
   ```

收起状态下仅显示图标栏，例如：

```text
新建
搜索
历史
收藏
设置
展开按钮
```

左侧视觉上应轻量，不能抢占中间和右侧主工作区。

---

### 5. 中间：AI 自然语言对话区

中间区域是用户和 AI 交互的核心区域。

需要包含：

1. 对话消息流  
   用户可以输入自然语言或公式，例如：

   ```text
   帮我画 y = x²
   画一条经过原点，斜率为 2 的直线
   把这条曲线改成红色
   再加一条 y = sin(x)
   解释这个函数的单调性
   ```

2. AI 回复内容需要支持结构化展示，例如：

   ```text
   已为你生成方程：y = x²

   类型：二次函数
   顶点：(0, 0)
   对称轴：x = 0
   开口方向：向上
   ```

3. AI 回复消息下方可以带快捷操作按钮：

   ```text
   绘制
   加入图像
   修改颜色
   解释图像
   导出
   ```

4. 底部输入框需要支持：

   ```text
   自然语言输入
   数学公式输入
   多行输入
   发送按钮
   清空按钮
   ```

5. 输入框上方可以设计快捷提示词按钮：

   ```text
   画一次函数
   画二次函数
   画三角函数
   比较两个函数
   求交点
   解释图像
   ```

6. 空状态设计  
   当新建会话时，中间区域显示欢迎语和示例提示：

   ```text
   你想绘制什么数学图像？
   例如：
   - 画 y = x
   - 画 y = x²
   - 比较 y = sin(x) 和 y = cos(x)
   ```

中间对话区需要有清晰的用户消息和 AI 消息区分。

### 6. 右侧：结果查看区

右侧是绘图和分析结果区域，是视觉重点。

建议右侧分为上下两部分：

```text
上方：函数曲线图区域，约 65%-75%
下方：方程列表 / 参数设置 / 图像分析，约 25%-35%
```

图像区域需要展示：

```text

网格线

图例
关键点
坐标刻度
鼠标悬停坐标提示
```

示例图像：

```text

y = x 红色曲线
```

曲线图区域应有工具按钮：

```text
放大
缩小
重置视图
平移
截图
全屏
```

下方区域中应包含当前绘制的方程列表，例如：


每个方程支持：

```text

修改颜色
删除
复制公式
查看分析
```

---

#### 6.3 参数设置

需要有坐标范围设置：

```text
x 范围：-10 到 10
y 范围：-10 到 10
网格：开/关
坐标轴：开/关
图例：开/关
采样精度：低 / 中 / 高
```

可以采用折叠面板或 Tab 形式展示。

---

#### 6.4 图像分析

可以展示 AI 对当前图像的分析结果，例如：

```text

顶点：(0, 0)
对称轴：x = 0
单调性：在 (-∞, 0) 上递减，在 (0, ∞) 上递增
零点：x = 0
```

#### 6.5 导出功能

```text
导出 PNG
```

### 9. 示例使用场景

请在设计稿中体现一个完整使用流程：

用户输入：

```text
帮我画 y = x²，并解释它的图像特征
```

AI 回复：

```text
已生成方程：y = x²

这是一个二次函数，图像是开口向上的抛物线。
顶点为 (0, 0)，对称轴为 x = 0。
```

右侧结果区显示：

```text
一条蓝色的 y = x² 曲线
坐标轴范围 x: -10 到 10, y: -10 到 10
方程列表中显示 y = x²
分析区域显示顶点、对称轴、开口方向
```

用户继续输入：

```text
再加一条 y = x，用红色显示
```

右侧结果区更新为：

```text
蓝色 y = x²
红色 y = x
```

方程列表同步显示两条曲线。

### 10. 视觉细节建议

1. 数学公式展示建议使用较清晰的公式样式，例如：

   ```text
   y = x²
   ```

2. 曲线颜色要有区分度，建议使用：

   ```text
   蓝色
   红色
   绿色
   紫色
   橙色
   ```

3. 当前选中的曲线可以加粗或高亮。

4. 操作按钮不要过多暴露，可以用图标按钮和更多菜单。

5. 右侧图像区域要尽量大，保证绘图体验。

6. 中间对话区要像 AI 助手，但不要过度聊天化，要保持工具效率。

7. 左侧会话区要轻量，避免视觉拥挤。

### 12. 总体目标

这个产品的核心目标是：

```text
让用户用自然语言快速生成数学方程图像，并能通过对话持续修改、分析和导出结果。
```

请围绕这个目标进行界面设计，确保：

```text
输入方便
反馈快速
图像清晰
状态明确
操作简单
适合长期保存和管理多个绘图项目
```
